# phemelo.work

Personal portfolio of Phemelo Moloi, styled as a tiling Hyprland desktop. Each section is a workspace, each block of content a tiled window, and scrolling switches workspace with a 3D tilt. A lazy-loaded three.js particle wallpaper reshapes itself for every workspace.

## Stack

React 18, TypeScript, Vite, Tailwind CSS, GSAP (ScrollTrigger), Lenis, three.js. Fonts (Martian Mono, Atkinson Hyperlegible Next) are self-hosted. Hosted on Firebase Hosting.

## Develop

```bash
npm install --legacy-peer-deps   # lenis declares an optional Nuxt peer that conflicts with Tailwind's jiti
npm run dev                      # http://localhost:8080
npm run build                    # type-check, fetch GitHub stats, bundle to dist/
npm run preview
```

## Content

All copy lives in [src/content/](src/content/): `profile.ts`, `experience.ts`, `projects.ts`, `skills.ts`. `github.json` is generated by `scripts/fetch-github.mjs` on every build (set `GITHUB_TOKEN` to avoid rate limits); the site makes no GitHub API calls at runtime.

Project screenshots shown in the phone and laptop mockups live in `public/shots/<shot>.avif|webp`. A project without a screenshot renders a styled placeholder. `node scripts/capture-screens.mjs` captures the live sites with a local Chromium.

## Contact form

Copy `.env.example` to `.env` and fill in the EmailJS keys. They are public by design, so also restrict allowed origins to `phemelo.work` and set a rate limit in the EmailJS dashboard. The form has validation, a honeypot field, a minimum fill time and a client cooldown.

## Deploy

```bash
npm run build
firebase deploy --only hosting
```

Security headers (CSP, nosniff, frame denial, referrer and permissions policy, caching) are defined in [firebase.json](firebase.json).
